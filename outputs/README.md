# Outputs

This folder contains lightweight sample outputs for quick inspection:

- `sample_prolmf_excerpt.xml`: a small ProLMF XML excerpt generated from the toolkit.
- `competency_question_outputs.md`: examples of SPARQL competency-query outputs.
- `quantitative_results.csv`: compact quantitative results.

The complete ProLMF export can be regenerated locally with the scripts in `prolmf/` when the full data source is available.
