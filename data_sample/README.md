# Data sample

This folder contains a local SQLite sample database and CSV extracts used to reproduce the demo scenario.

Files:

- `prolexbase_sample.db`: SQLite database used by the Streamlit app.
- `sample_pivot.csv`: sample pivots.
- `sample_prolexeme_arb.csv`: sample Arabic prolexemes.
- `sample_derivative_arb.csv`: sample derivatives.
- `sample_instance_arb.csv`: sample inflected instances.
- `sample_type.csv`: sample semantic types.
- `sample_morphology_arb.csv`: sample morphological values.

Do not commit private MySQL credentials or non-public dumps without checking data rights.
