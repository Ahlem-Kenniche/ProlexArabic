# Arabic morphological generator

This directory contains the executable Arabic morphological rule implementation and lightweight tests used by the ProlexArabic demonstration.

- `arabic_rules.py` contains the rule implementation retained in the EACL package.
- `test_rules.py` and `test_instances.py` provide representative checks.
- The internal detailed entity-list documentation used during development is not distributed because it is not required to execute or reproduce the demonstration.

The repository therefore exposes the generation logic needed for inspection and testing without publishing ancillary development inventories that are not runtime dependencies.
